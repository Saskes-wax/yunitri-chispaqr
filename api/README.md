# api/ — backend (Triztan)

Node.js 20 + Express. Monolito modular: una carpeta por módulo del contrato (M1 Mesas y QR, M2 Carta, M3 Pedidos, M4 Caja, M5 Cocina, M6 Usuarios).
Prefijo de rutas `/api/v1`. Lista de endpoints en [`docs/api/endpoints.md`](../docs/api/endpoints.md).

No se crean tablas aquí: el esquema es de Iván (`database/`).
